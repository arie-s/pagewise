Pagewise — User Guide

A local-first PDF editor. Your documents never leave your machine.

Basic workflow

Open a PDF: click Open PDF, or simply drag a PDF onto the window. The last document you had open reopens automatically on launch.

Open images: open or drop one or more PNG/JPEG images (photos, screenshots, scans) and they become a PDF with one page per image, in filename order, with phone-photo rotation applied. The first save asks where to write the PDF; the original images are never overwritten.

Annotate: pick a tool on the toolbar (hover any button for a description), click or drag on the page. Everything is drawn as you go.

Save: Ctrl+S. Annotations are baked permanently into the saved file — this is intentional, like printing a stamp onto paper. The app warns you if you close with unsaved changes.

Tweak the look: View → Light / Dark Theme (Ctrl+Shift+T).

Page operations

  • Reorder pages: drag thumbnails in the left sidebar onto another page. A blue line shows where the page will land.
  • Delete / rotate / insert pages from the right panel or the Page menu. Rotate All affects every page at once.
  • Insert pages from another PDF (right panel) — picks up where copy-and-paste never did.
  • Extract pages: Page → Extract Pages..., then save the selection as its own file.

Multi-document operations

  • Merge PDFs: welcome screen button, or File → Merge PDFs... — pick multiple PDFs or PNG/JPEG images in order; you can then reorder pages by dragging thumbnails.
  • Split PDF: File → Split PDF... — every N pages, or custom ranges like 1-3,5,7-10.

Security

Security → Set Password Protection adds real AES-256 encryption. Remove Password decrypts with the current password. Note: encrypted PDFs are saved as new files — the editor holds your working copy unencrypted while you edit.

Redact: use Tools → Redact → Mark for Redaction, drag over the content, then save. Applying redactions rebuilds the entire document from rendered images with opaque black masks, removing the original text, images and hidden objects. Text selection, forms, links, bookmarks and metadata are removed from the output. The app asks before applying this change; canceling Save keeps your pending edits.

OCR — reading text out of images

If a PDF is a scan or photo, it has no real text: you can't search or copy from it. Two tools fix that:

Make SearchableSmart Extract (AI)
What it givesInvisible text layer inside the PDF — the file stays visually identical, but search, Ctrl+F and copy now worka markdown transcript for copying or saving, plus tables as CSV (Export CSV) or ready to paste into a spreadsheet (Copy table) — the PDF is not modified
Strengthtyped/printed pages; fast, works everywheretables, columns, formulas, handwriting, messy scans
Setupnone (15MB language pack once)one-time ~4.5GB download via Tools → Setup AI Reading Engine

Tip: run both on a scanned document — searchable for finding things, Smart Extract for a clean copy-paste of tables.

Tables that continue across pages with the same header row are exported as one table. Cells that start like a spreadsheet formula (for example =) are saved with a leading ' so opening the CSV can't run them.

Command line (for automation)

Merge, split, encrypt, decrypt, document info and AI engine commands are scriptable. Run npm run cli -- ... from the source folder, or the packaged binary followed by cli. Examples:

... cli merge out.pdf a.pdf b.pdf c.pdf
... cli split doc.pdf --every 5 or --ranges 1-3,5,7-10
... cli encrypt doc.pdf --password secret
... cli decrypt doc.pdf --password secret
... cli info doc.pdf
... cli engine-extract page.png (after engine install; add --csv out.csv to save tables)

Privacy

Everything runs on your machine. There are no accounts, no telemetry, no cloud inference. Internet access is used to download OCR language data and the optional AI engine/model. AI document processing uses a local server bound to 127.0.0.1.

Troubleshooting

  • OCR says it needs language data — allow internet once; it downloads ~15MB and caches it.
  • Smart Extract says engine not installed — Tools → Setup AI Reading Engine → Download & Install (~4.5GB, one time).
  • Smart Extract is slow — processing speed depends on the computer, page and available GPU acceleration. CPU inference can be substantially slower.
  • Encrypted PDF won't open — the editor needs the password; open it from File → Open and enter it if prompted.
  • Lost recent files list — settings are stored per user account in Electron's app data directory. Data from earlier versions of the app is reused on first launch when available.
