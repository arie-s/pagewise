Pagewise — User Guide

A PDF editor that works on your own computer. Your documents never leave it.

1. Getting started

  • Open a PDF: File → Open PDF (Ctrl+O), or drag a PDF onto the window. File → Open Recent lists earlier files, and the last document reopens when you start the app.
  • Open pictures: open or drop PNG/JPEG photos, screenshots or scans. They become a PDF with one page per picture, in filename order. The first save asks where to put the PDF; the pictures are never overwritten.
  • Save: Ctrl+S, or File → Save As. The app warns you if you close with unsaved changes.
  • Undo and redo: Ctrl+Z / Ctrl+Y.
What gets saved: highlights, underlines, strikethroughs and sticky notes are saved as real PDF comments. Other PDF programs show them, and you can still change or remove them later. Drawings, shapes, added text, stamps, images and signatures become part of the page when you save, like ink on paper. Form answers are saved as form data until you flatten the form (see Filling forms).

Use View → Light / Dark Theme (Ctrl+Shift+T) to change the look.

2. Reading and finding

  • Zoom: View → Zoom In / Zoom Out / Actual Size, or the toolbar buttons.
  • Side panel: the Pages tab shows thumbnails; the Bookmarks tab shows the document's outline (click an entry to jump); the Comments tab is described in section 5.
  • Find: Edit → Find (Ctrl+F) highlights every match on every page. Aa matches upper and lower case exactly, Ab| matches whole words only. Enter and Shift+Enter step to the next and previous match. This only works on pages that contain real text; for a scan, see section 9.
  • Go to a page: Ctrl+G, or the Page menu (first, last, previous, next).

3. Filling forms

Fill a form: in a form that already has fields, click a field with the Select tool, then type, tick a box or choose from a list. Answers are saved into the file.

A form with no fields (a flat PDF or a scan): Forms → Detect Fields Automatically finds the blank lines and boxes and makes them fillable, naming each after the text beside it. Right-click a field to remove it.

Fix or add fields: Forms → Add Field (Text Field, Checkbox or Dropdown), then drag on the page. Forms → Move & Resize Fields lets you drag a field, drag its corner to resize it, or press Delete to remove it. Right-click a field and choose Field Properties to rename it or set multi-line, maximum length, font size, read-only, required and dropdown choices.

Fill from Profile: save your details once with Forms → Manage Profiles... (kept on this computer only). You can keep several, for example one for you and one for your spouse. Forms → Fill from Profile proposes a value for each matching field. Choose who you are filling as, and a spouse profile if the form has spouse fields, then review the list and untick anything you do not want. Social Security number and date of birth are never filled unless you tick them, and fields about other people (dependents, a requester) are left alone.

AI suggestions: for fields your profile cannot fill, a Suggest the rest with AI button appears in that review window. It uses the optional AI writing helper (section 13) to guess answers or write short drafts from your profile. Suggestions are never ticked for you and are always yours to review; anything not found in your profile is flagged. The first use asks before downloading the helper.

Build a profile from what you have: Forms → Save Filled Answers to a Profile turns the answers in a filled form into profile details. Forms → Create Profile from This Document reads an ID card, bill or letter (the first three pages; it needs the AI writing helper, and the AI reading model for scanned pages). Both end in a review window and save nothing until you click Save; Social Security number and date of birth start unticked.

Flatten: Forms → Flatten Form (make answers permanent) turns the answers into ordinary page content. They can no longer be edited, and every PDF reader shows them the same way.

4. Signing

  • Add Signature (toolbar): choose Draw, Type (three styles) or Upload a picture of your signature (tick Remove white background to make the white transparent). The Initials tab does the same for initials. Save for next time keeps them on this computer, and saved ones appear in the window to reuse.
  • Place it: click the page, or drag a box. Drag a placed signature to move it, drag its corner to resize it, and press Delete to remove it.
  • Forms → Sign Document... finds the signature fields and signature lines in a form and places your signature in each one, filling in the date beside it. Check the result before saving.

5. Comments and markup

  • Sticky note: Tools → Annotation Tools → Note (or the Note button), then click the page and type. Click a note later to read, edit or delete it.
  • Highlight, underline, strikethrough: choose the tool and drag over text. Or select text and press the Comment button that appears to highlight it and add a note in one step.
  • Comments panel: the Comments tab lists every comment by page with its author, date and text. Click one to jump to it. You can Reply, Edit, Delete and Mark Completed / Reopen, search, and filter by All / Open / Completed. Ctrl+Z undoes these.
  • Your name: click the name at the top of the Comments tab to change the author shown on new comments.
  • Drawing and shapes: Tools → Drawing Tools (Pen, Eraser) and Shape Tools (Rectangle, Circle, Line, Arrow), plus Add Text, Stamp and Add Image. Clear All in the right panel removes your unsaved drawings and redaction marks.

6. Editing text

Find & Replace (Edit → Find & Replace..., Ctrl+H) changes the words inside the PDF itself. The old letters are removed, not covered. Replace changes the current match and Replace All every match; Ctrl+Z undoes it. Limits:

  • It needs real text, so it does not work on scans.
  • It works within one line at a time; it does not reflow a paragraph.
  • It uses the PDF's own font when it has the letters you type. If a letter is missing, it uses a similar standard font.
  • On a digitally signed PDF it asks first, because any change breaks the signature.

Double-click a word to type a different one in its place. This covers the old word with a white box and writes the new word on top, so the old text is still inside the file and can be found or copied. For a real change, use Find & Replace. To permanently remove sensitive text, use Redact (section 12).

7. Pages

  • Reorder: drag thumbnails in the left panel; a blue line shows where the page will land.
  • Rotate, insert, delete: from the right panel or the Page menu. Rotate All turns every page. Insert Pages From File... adds pages of another PDF after the current page.
  • Replace Page... swaps the current page for a page of another PDF. Extract Pages... saves chosen pages as their own file.
  • Crop Page... hides everything outside a rectangle you drag (it is hidden, not deleted; Remove Crop brings it back). Resize Pages... fits the content to A4, Letter, Legal or A5.
  • Add Watermark, Add Header & Footer and Add Page Numbers are in the Page menu.

8. Combining and splitting

  • Merge: File → Merge PDFs... (or the button on the welcome screen). Pick several PDFs or pictures in order, then reorder pages by dragging thumbnails.
  • Split: File → Split PDF... every N pages, or custom ranges like 1-3,5,7-10.

If you are unsure, start with Recognize Text (fast). Use the AI versions when its result is poor or you need tables. A table that continues over several pages with the same header row is exported as one table. Cells that start like a spreadsheet formula (for example =) are saved with a leading ' so opening the file cannot run them.

10. Converting and exporting

  • File → Export → Word Document (.docx)... and Excel Workbook (.xlsx)... convert the whole document or a page range. Digital pages convert directly; scanned pages (and every page, if you tick the AI option) use the AI reading model.
  • File → Export → Export as Images (PNG) / (JPEG) saves each page as a picture.
  • File → Export → Export Selected Pages... saves chosen pages as a new PDF.

11. Smaller files

File → Reduce File Size... lowers the resolution of scans and photos and re-saves them as JPEG. Choose Smallest (100 dpi), Balanced (150 dpi, recommended) or High quality (220 dpi). Text and vector graphics are not changed.

12. Security

Security → Set Password Protection... adds real AES-256 encryption. Remove Password decrypts with the current password. An encrypted PDF is saved as a new file, because the editor holds your working copy unencrypted while you edit.

Redact: use Tools → Redact → Mark for Redaction, drag over the content, then save. Applying redactions rebuilds the entire document from rendered images with opaque black masks, removing the original text, images and hidden objects. Text selection, forms, links, bookmarks and metadata are removed from the output. The app asks before applying this change; canceling Save keeps your pending edits.

14. Privacy, shortcuts, command line, troubleshooting

Privacy

Everything runs on your machine. There are no accounts, no telemetry, no cloud inference. Internet access is used only to download OCR language data and the optional AI models. The AI features use a local server bound to 127.0.0.1. Profiles stay on this computer.

Keyboard shortcuts

Use Cmd instead of Ctrl on macOS. Full list: Help → Keyboard Shortcuts (Ctrl+/).

Ctrl+O open · Ctrl+S save · Ctrl+F find · Ctrl+H replace · Ctrl+G go to page · V H T P E select/hand/text/pen/eraser · L A R C line/arrow/rectangle/circle

Command line (for automation)

Merge, split, encrypt, decrypt, document info and AI reading model commands are scriptable. Run npm run cli -- ... from the source folder, or the packaged binary followed by cli. Examples:

... cli merge out.pdf a.pdf b.pdf c.pdf
... cli split doc.pdf --every 5 or --ranges 1-3,5,7-10
... cli encrypt doc.pdf --password secret
... cli decrypt doc.pdf --password secret
... cli info doc.pdf
... cli engine-extract page.png (after the AI reading model is installed; add --csv out.csv to save tables)

Troubleshooting

  • Recognize Text says it needs language data — allow internet once; it downloads about 15 MB and keeps it.
  • An AI feature says the AI reading model is not installed — Tools → Scanned Pages → Download AI Reading Model... → Download & Install (about 4.5 GB, once).
  • AI reading is slow — speed depends on the computer, the page and whether a graphics card is used. Processor-only reading can be much slower.
  • Find or Replace finds nothing — the page may be a scan; use Recognize Text first.
  • Encrypted PDF won't open — the editor needs the password; open it from File → Open PDF and enter it when asked.
  • Recent files list is empty — settings are stored per user account in Electron's app data folder. Data from earlier versions is reused on first launch when available.
